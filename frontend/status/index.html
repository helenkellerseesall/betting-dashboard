ml scorer (logistic model)

…
The engine has a trained ML model that scores each prop's hit probability. It's loaded once at backend boot from backend/ml/model.json and fed into 10 cognition modules. A stale model = April patterns scoring June props. The dampener above provides per-family backstop but doesn't fix ranking shape. If older than 30 days, the engine is using outdated weights — retrain via backend/ml/train.py or disable via scorer.js.
